Übung 5: Eine Schulklasse verwalten
Thema: Objekte in einer ArrayList, Objekte als Parameter

Schueler ist schon fertig. Die Klasse Schulklasse speichert Schüler in einer
ArrayList; ihre Methoden fehlen noch.

1. aufnehmen(s) fügt den Schüler zur Liste hinzu.
2. anzahl() liefert, wie viele Schüler in der Klasse sind.
3. besteNote() liefert die beste (kleinste) Note, für eine leere Klasse 0.
4. suche(name) liefert den Schüler mit diesem Namen, sonst null.

Probier es zuerst auf der Objektbank aus: Erzeuge eine Schulklasse und zwei
Schueler und übergib die Schüler an aufnehmen. Dann die Tests in SchulklasseTest.

Tipp: Namen vergleichst du mit equals, nicht mit ==.
