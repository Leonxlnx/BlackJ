Übung 4: Noten auswerten
Thema: Arrays, Schleifen, Durchschnitt

Die Klasse Statistik wertet ein Array von Noten aus.

1. maximum(werte) liefert den größten Wert im Array.
2. durchschnitt(werte) liefert den Mittelwert als double.
   Für ein leeres Array ist das Ergebnis 0.
3. anzahlUeber(werte, grenze) zählt, wie viele Werte größer als grenze sind.

So prüfst du dich: Kompilieren, dann Rechtsklick auf StatistikTest und
"Tests ausführen".

Tipp: Auf der Objektbank gibst du ein Array so ein: {2, 3, 1}.
Achte beim Durchschnitt darauf, nicht ganzzahlig zu teilen.
